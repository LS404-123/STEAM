# 免程式模式二控制板：F 版候選電路

這份圖以 SN74HC14DR＋SN74HC74DR 實現「SW1 正轉 → SW2 反轉 → SW1 停止」，不需要燒錄。已完成原理圖及邏輯檢查，尚未製作 F 版 PCB，也未做實機測試。舊 E／E1 版 PCB 不能直接用這份物料表裝配。

## 如何看圖

先開「新電路圖-F.pdf」，可以放大查看接腳和元件值。要編輯，將整個資料夾解壓後，用 KiCad 開啟 `mode2-no-firmware.kicad_pro`，再開原理圖。

圖中同名標籤代表相連，例如所有 VCC 接在一起，所有 GND 接在一起。VCC 是經 S0 開關後的電池正極；BATT+ 是開關前的電池正極。IC 旁的小數字是接腳編號。

## 接線和操作

| 端子 | 接線 |
|---|---|
| P1 電池 | 1：兩粒 AA 電池盒正極；2：負極 |
| P2 SW1 | 兩條線接微動開關 COM、NO，次序不限；NC 不接 |
| P3 SW2 | 兩條線接微動開關 COM、NO，次序不限；NC 不接 |
| P4 馬達 | 1：M1；2：M2。方向相反時交換兩條馬達線 |

四組均採用兩位螺絲端子，實際型號及孔距仍須在 PCB 佈局前定案。C8 是板外的 100nF 陶瓷電容，直接焊在馬達兩端。

裝好兩粒 AA，開啟板上 S0。正常上電後馬達停止。每次按鍵均指按下後放開；不設三秒鎖定。

| 現在狀態 | 按 SW1 | 按 SW2 |
|---|---|---|
| 停止 | 正轉 | 保持停止 |
| 正轉 | 保持正轉 | 反轉 |
| 反轉 | 停止 | 保持反轉 |

停止後，放開 SW1 再按即可啟動。上述操作以逐個按鍵為準；同時按兩個開關的結果未定義。

## 各部分的作用

- **U1 SN74HC14DR：整理開關訊號。** R1–R4、C5、C6 配合施密特輸入消抖，避免一次按下被視為多次。另兩個反相器配合 R5、C7、D1 產生上電復位訊號。
- **U2 SN74HC74DR：記住目前狀態。** 第一個觸發器保存 RUN，第二個保存 REV。RUN=0 是停止；RUN=1、REV=0 是正轉；RUN=1、REV=1 是反轉。按 SW1 時，RUN 讀取「不是 REV」；按 SW2 時，REV 讀取 RUN。RUN 降為 0 也會清除 REV。
- **U3 DRV8212DSGR：向馬達供電。** RUN 接 EN、REV 接 PH；MODE 固定接 VCC。它按狀態改變馬達兩端的極性。EN=0 時先制動，再自動進入休眠；不需要 LED 或模式跳線。
- **C1–C4：穩定板上電源。** C1–C3 靠近 IC，C4 放在馬達驅動器供電附近。C8 放在馬達本體。
- **S0、R6：電源開關和關機放電。** S0 的公共端接 VCC，ON 接電池正極，OFF 經 R6 接地，讓關機後的電容放電。這不是把電池正極短接地。

## 元件選擇與限制

SN74HCS125PWR 是施密特緩衝器，不能自行記住運轉／方向，也不能按接腳直接替代 HC74 或本圖的 HC14。本方案用 HC14＋HC74，避開 HCS74 的採購問題。

HC14、HC74 的額定供電為 2–6V。本圖供兩粒 AA 使用，負載下邏輯電源須維持至少 2V；電池耗盡後不保證工作。DRV8212 最低供電為 1.65V。沒有採用最低供電 2.7V 的 DRV8833，因為它不能完整涵蓋兩粒 AA 的使用電壓。

**Q1 已在本候選圖取消，條件是 S0 能直接切換馬達電流。** S0 的型號、封裝和 DC 馬達負載額定尚未定案，先以至少 3A DC 等級作篩選，再核對廠商負載規格。原本 50mA 的 MSK12C02 不適用此接法，不能照搬其封裝。

補查的 C&K **1101M2S3CQE2** 是 PCB 直插 SPDT，Q 銀接點規格為 6A／28V DC，本體約 12.70×6.60mm，接點組合為 1–2／2–3，與本圖 S0 電氣接法相符。但[立創頁面](https://www.lcsc.com/product-image/C221538.html)顯示缺貨、單件參考價約 US$6.40；不符合本案低成本採購方向，因此**未選入物料表**。這項查核說明取消 Q1 仍要付出開關體積與成本的代價，並未完成小型低價 S0 的選型。規格來源：[C&K 原廠 1000 系列資料表](https://www.ckswitches.com/media/1429/1000.pdf)。

本圖板上共 **22 個零件**（3 IC、6 電阻、7 電容、1 二極管、1 電源開關、4 端子），另有板外開關、馬達及 C8。舊 E／E1 版是 14 個；免燒錄不等於零件更少。此處沒有宣稱已達理論最少零件數或最小板面積。

## 已做的檢查

- KiCad 原理圖 ERC：0 項違規，未透過停用規則排除錯誤。
- 從 KiCad 匯出的實際網表核對 81 個接腳連接。
- 1,024 組、每組 10 次按鍵的順序檢查通過。
- 2V 下 28 個指定 RC／門檻情境通過；測試的 5ms 接點彈跳只產生一次按鍵事件。

這些是接線、數位狀態和簡化 RC 模型檢查，並非 SPICE 或實機驗證，不能證明實際馬達啟動、反轉瞬態、電源干擾或所有微動開關彈跳都通過。F 版尚無 PCB，因此也沒有 F 版 DRC、銅線角度檢查或 3D 板圖；後續佈線仍須遵守不使用 90° 銅線轉角的要求。
