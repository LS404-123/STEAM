# 模式二 G 版：40 × 40 mm

一塊 PCB，板厚 1.6 mm、兩層銅線、22 個零件全部裝正面。使用兩粒 AA；無 MCU／程式、LED、模式跳線或 Q1。保留 PCB 上的大電流 S0 和四組螺絲端子。**此為設計原型，尚未實機測試。**

## 使用手冊與圖像

- `exports/模式二控制板G版使用手冊.pdf`：7 頁，含接線、操作、工作原理、PCB 正背走線圖、3D 圖及最後一頁 A3 原理圖；不含 R／C 計算。
- `exports/原理圖-G.pdf`：獨立原理圖。
- `exports/PCB-3D.png`、`PCB正面.png`、`PCB背面.png`：原生 KiCad 3D 算繪圖，並非實物照片。
- `exports/pcb-traces-front.png`、`pcb-traces-back.png`：走線圖；SVG 是可放大的向量版。背面圖已翻轉為從板背觀看。
- `exports/完整3D板.wrl`：包含模型的獨立 VRML，單位 mm。端子、S0、U3 模型僅表達尺寸外形。

## 開啟 KiCad

解壓完整專案，保留資料夾結構。用 KiCad 10 開啟 `mode2-no-firmware.kicad_pro`，再開啟 PCB 編輯器並按 **Alt＋3** 查看 3D。`BoardF.pretty` 是沿用並隨包附上的封裝庫名稱，不代表這是 F 版的板。實際版本以板上 MODE 2 / G 和 40 × 40 mm 為準。

## 放大後的改變

| 項目 | F 版 | G 版 |
|---|---|---|
| PCB 尺寸 | 28 × 28 mm | 40 × 40 mm |
| 面積 | 784 mm² | 1,600 mm²，約 2.04 倍 |
| 電源及馬達主幹 | 0.60 mm | 1.00 mm |
| 零件數量 | 22 | 22 |
| 一般過孔 | 36 | 44，其中 8 個是接地過孔 |

G 版重新安排端子、位號與電源區，接線空間較充裕，並有較大的接地鋪銅空間。晶片的去耦電容仍靠近對應晶片。走線加闊可減少同長度銅線的電阻，但路徑長度也有改變，未量測整板功耗、溫升或電池壽命，不能宣稱有特定效率提升。沒有安裝孔；端子及 U3 封裝大小未改變。

## 接線及操作

以零件面朝上、S0 在左上角為基準：

| 接口 | 接法 |
|---|---|
| P1／BAT，右上 | 上孔負極，下孔正極；只接兩粒 AA 串聯 |
| P4／MOTOR，右側中間 | 上孔 M2，下孔 M1；若轉向相反，關機後交換兩線 |
| P2／SW1，左下 | 左孔 NO，右孔 COM |
| P3／SW2，下方中間 | 左孔 NO，右孔 COM |

機械微動開關用 COM／NO，NC 不接。不要只靠線色判斷接點。C8 是板外 100nF 陶瓷電容，直接跨接馬達兩端，不接 GND。接線前關機、取出電池，鎖好後輕拉線頭確認。

放開兩個開關再開 S0：馬達應停止。每次按下後放開，一次只按一個開關。

| 目前狀態 | 按 SW1 | 按 SW2 |
|---|---|---|
| 停止 | 正轉 | 保持停止 |
| 正轉 | 保持正轉 | 反轉 |
| 反轉 | 停止 | 保持反轉 |

沒有三秒鎖定；停止後放開再按 SW1 可重新啟動。同時按兩鍵的行為未定義。

## 零件及裝配

詳見 `BOM.csv`。本次沒有更改 F 版的型號與數值。

- U1：SN74HC14DR，SOIC-14；U2：SN74HC74DR，SOIC-14。
- U3：DRV8212DSGR，WSON-8，表面標記 212；底部散熱焊盤必須焊接，建議交貼片店回流焊。
- S0：C&K 1101M2S3CQE2，PCB 直插，4.70mm 腳距、1.85mm 孔徑，銀接點 6A／28V DC。不可直接換成焊耳 Z 或直角 A 版本。這是成本較高的開關，本次未更換它；採購前確認供貨與價格。其他型號須先核對接腳、尺寸及 DC 額定。
- 端子：KEFA KF128-2.54-2P C474920，2.54mm 腳距、1.30mm 孔徑，不是 5.08mm 版本。
- C4 正極朝板下方；D1 色帶端朝左。S0 和四組端子從正面插入、背面焊接。
- 使用者提供的商品圖可核對部分型號及封裝，不能保證即時庫存或真偽。

## 製板

使用 `mode2-gerbers-rev-g.zip`，或專案內 `fabrication/` 同一組檔案。詢價條件：FR-4、40 × 40 mm、2 層、1.6 mm、1oz 銅、綠色阻焊；表面處理由貼片店確認適合 WSON。這是同一塊板的兩面銅線，不是兩塊板。

一般訊號 0.25mm，WSON 短引出線 0.20mm，電池及馬達主幹 1.00mm；DRC 間距 0.20mm。44 個 0.30mm 過孔，另有 U3 的兩個 0.20mm 散熱孔、8 個端子孔、3 個 S0 孔，合共 57 個鍍通孔。沒有非鍍通孔。

## 檢查結果及限制

- ERC 0 違規；DRC 0 違規、0 漏接、0 原理圖一致性問題。
- 實際 PCB 尺寸、22 個正面零件、接腳、封裝及 3D 模型均已核對。
- 81 個原理圖接腳連接、1,024 組按鍵順序、28 個指定 RC 彈跳模型情境通過。
- 0 個 90° 銅線轉彎；焊盤內接合及 T 形分支另列於 `reports/angles.json`。
- 使用手冊共 7 頁，已逐頁檢視；所有圖像由 G 版原生設計檔輸出。

尚未實機測試馬達啟動、反轉、溫升、干擾及不同微動開關的消抖。兩粒 AA 在負載下須維持至少 2V。沒有額外固定 0.8A 限流，DRV8212 的內建保護不是精確限流器。不要故意卡住馬達。

原廠資料：[HC14](https://www.ti.com/lit/ds/symlink/sn74hc14.pdf)、[HC74](https://www.ti.com/lit/ds/symlink/sn74hc74.pdf)、[DRV8212](https://www.ti.com/lit/ds/symlink/drv8212.pdf)、[S0 圖面](https://www.ckswitches.com/media/1429/1000.pdf)、[馬達驅動佈局指南](https://www.ti.com/lit/an/slva959b/slva959b.pdf)。

## 重建

一般使用者直接開啟專案即可。進階重建：用 KiCad Python 依次執行 `build_schematic.py`、`build_board.py`、`route_board.py`，先執行一次 DRC 產生 `reports/drc.json`，再執行 `finish_board.py`，最後執行 `export_and_check.ps1`。路徑依電腦調整。

使用 bundled Node 的 sharp 將兩個走線 SVG 輸出為 1800px PNG（density 150），並以 `pdftoppm` 輸出原理圖 PNG。使用帶 reportlab／pypdf 的 Python 執行 `build_manual.py`，逐頁檢視 PDF 後再執行 `package.py`。不要在修改 PCB 後沿用舊圖像、手冊或 Gerber。
