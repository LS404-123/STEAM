# 模式二 F 版：PCB 與 3D 圖包

**28 × 28 mm，板厚 1.6 mm，雙層銅線，22 個零件全部裝在正面。**

保持免燒錄、無 Q1、無 LED、無模式跳線；板上使用較大電源開關，電池、馬達和兩個微動開關均用螺絲端子。這是可交付打樣的設計檔，尚未製成實物測試；舊 E／E1 板和舊使用手冊不能代替本版資料。

## 開啟 PCB 和 3D

1. 解壓整個專案，保留資料夾結構。
2. 用 KiCad 10 開啟 `mode2-no-firmware.kicad_pro`。
3. 開啟 PCB 編輯器，再按 **Alt＋3** 看 3D，拖曳可旋轉。

不需要 KiCad 也可直接看 `exports/PCB-3D.png`、`PCB正面.png`、`PCB背面.png`。`完整3D板.wrl` 是含模型的獨立 VRML 檔，輸出單位為 mm。

`正面佈線.svg`／`背面佈線.svg` 可以放大查看銅線；背面圖已翻轉成從板背觀看的方向。對應 PNG 是圖片版。`原理圖-F.pdf` 是與此 PCB 一致的電路圖。

## 為何使用雙層

此版是**單面裝零件、雙層銅線**，背面有銅線及穿孔焊點，沒有背面零件。雙層可讓訊號交叉並保留接地鋪銅，避免為單層佈線增加跳線或放大板子。

JLCPCB 的公開入門方案已包括小量雙層板，因此沒有證據顯示此板改單層會更便宜；實際價錢仍須按數量、工藝及運費報價。這不是一份單層與雙層的正式配對報價。[製板商說明](https://jlcpcb.com/help/article/how-do-i-place-an-order)

目前尺寸是在保留兩粒 SOIC-14、四組 2.54mm 螺絲端子及較大 S0 下完成的緊湊佈局，已檢查元件間距；沒有宣稱是所有封裝與排列的理論最小值。未增加安裝孔。

## 接線

以下方向以正面朝上、S0 在左上角為準；板背也印有標示。

| 接口 | 位置與接法 |
|---|---|
| P1／BAT | 右上角；下孔為電池正極，上孔為負極；只用兩粒 AA 串聯 |
| P4／MOTOR | 右側中間；下孔 M1，上孔 M2；若轉向相反，交換兩條馬達線 |
| P2／SW1 | 左下角；左孔接微動開關 NO，右孔接 COM |
| P3／SW2 | 下方中間；左孔接 NO，右孔接 COM |

SW1／SW2 使用瞬時機械微動開關，NC 不接。兩條開關線交換亦不影響功能。C8 是板外 100nF 陶瓷電容，直接焊在馬達兩端。

## 操作

S0 撥到 ON，上電後馬達停止。按鍵均需按下後放開。

| 目前狀態 | 按 SW1 | 按 SW2 |
|---|---|---|
| 停止 | 正轉 | 保持停止 |
| 正轉 | 保持正轉 | 反轉 |
| 反轉 | 停止 | 保持反轉 |

停止後放開 SW1，再按即可啟動，沒有三秒鎖定。U1 整理按鍵訊號，U2 記住狀態，U3 驅動馬達；無須輸入程式。同時按兩個開關的行為未定義。

## 購買和裝配

- 完整物料見 `BOM.csv`。U1、U2 應選 **SN74HC14DR、SN74HC74DR，SOIC-14**；U3 選 **DRV8212DSGR，WSON-8，標記 212**。
- S0 已按 **C&K 1101M2S3CQE2** 的原廠尺寸製作封裝：三腳、4.70mm 腳距、1.85mm 孔徑、12.70×6.60mm 本體，Q 銀接點額定 6A／28V DC。不要買焊耳 Z 或直角 A 尾碼版本。[原廠圖面](https://www.ckswitches.com/media/1429/1000.pdf)
- 此 S0 是有明確尺寸與 DC 額定的選型，並非低價通用小開關。先前分銷商頁面單件參考約 US$6.40 且缺貨，會是主要採購成本；製板前需取得該型號。採用其他開關前須核對尺寸、腳位和 DC 額定。[供應頁面](https://www.lcsc.com/product-image/C221538.html)
- 四組端子是 **KEFA KF128-2.54-2P**，不要買 5.08mm 孔距版本。
- C4 有極性，正極朝板下方；D1 色帶端朝左。U3 底部焊盤需要焊接，適合交由貼片店回流焊。端子及 S0 是正面插入、背面焊接。
- 使用者提供的商品圖已核對 U2、U3 型號及封裝；U1 圖片可見 HC14 標記，購買時依上述完整 DR 型號。圖片不代表即時庫存。

## 製板檔

交給製板商的是獨立的 Gerber ZIP；專案內 `fabrication/` 也有同一組檔案。建議詢價條件：FR-4、28×28mm、2 層、1.6mm、1oz 銅、綠色阻焊、一般表面處理。表面處理應由貼片店確認可焊接 WSON-8；不要把此檔下單成單層板。

銅線最細 0.20mm（WSON 短引出段），一般訊號 0.25mm，電池及馬達主幹 0.60mm；間距按 0.20mm 檢查。共 36 個一般過孔，另有 U3 封裝內兩個 0.20mm 散熱孔。鑽孔檔另列 8 個端子孔及 3 個 S0 孔。

3D 中的端子、S0、U3 模型按尺寸作外形示意，並非廠商完整機械模型；其餘使用 KiCad 標準模型。裝配及打板以原理圖、BOM、封裝和 Gerber 為準。

## 檢查結果與範圍

`verification.json` 和 `reports/` 保存實際檢查結果：

- ERC 0 違規；DRC 0 違規、0 漏接、0 原理圖一致性問題。
- 22 個零件、全部正面裝配，PCB 接腳對照原理圖通過。
- 1,024 組按鍵順序及 28 個指定 RC 彈跳情境通過。
- 0 個 90° 銅線轉彎；T 形分支及焊盤內接合另列於角度報告，不當作轉彎。
- 3D 模型檔齊全，正反面與立體圖已檢視。

這些不是實機或馬達瞬態測試。兩粒 AA 在負載下須維持至少 2V 才符合邏輯 IC 的工作範圍；沒有另設可調電流限制，DRV8212 的內建保護不等於固定 0.8A 限流。首次打樣仍需測試指定馬達的啟動、反轉及實際微動開關消抖。

原廠電氣資料：[HC14](https://www.ti.com/lit/ds/symlink/sn74hc14.pdf)、[HC74](https://www.ti.com/lit/ds/symlink/sn74hc74.pdf)、[DRV8212](https://www.ti.com/lit/ds/symlink/drv8212.pdf)。標準封裝及模型來源：[KiCad Libraries](https://www.kicad.org/libraries/)。

## 重建與重查

一般使用者直接開啟專案即可。需要重建時，在 KiCad 10 的 Python 中依次執行 `build_schematic.py`、`build_board.py`、`route_board.py`；先跑一次 DRC 產生 `reports/drc.json`，再執行 `finish_board.py`，最後用 `export_and_check.ps1` 重查及匯出。腳本的 KiCad 安裝路徑需按電腦調整。

製板圖由 KiCad 原生工具產生。`route_board.py` 是此固定尺寸與接腳配置的專用工具，修改元件位置後不可跳過 DRC 與人工檢視。
